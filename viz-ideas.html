Ways to show many museum objects as dots

These sketches focus on dot-based views rather than real object thumbnails, so the emphasis stays on patterns, density, and relationships across the collection.

01

network

Dots can cluster into a network to reveal objects that are connected by shared stories, makers, places, or themes.

group by object type
02

maps

Dots placed on a map can show where objects came from, where they moved, or where their stories are rooted geographically.

Use dot size, color, or halo to distinguish object type, origin, or collection.
03

timeline

A timeline can stack dots by date so people can see bursts, gaps, and changes in object type over time.

1900

early cluster

Small dense dot group showing a first wave of objects entering the collection.

1950

type shift

More spread out dots to show changing object types and broader collecting patterns.

2020

recent activity

New dot clusters can surface recent acquisitions or digitization milestones.

Five UX questions for visitors

Use these prompts to see whether people understand the concept, find the views useful, and know what to do next.

1

What do you think this dot view is showing?

Checks whether the main idea is immediately understandable.

2

Which view helps you explore museum objects most easily?

Compares network, map, and timeline patterns.

3

What information would you want the dots to reveal on hover or click?

Surfaces expectations for interaction detail.

4

Is there a type of object or filter you would want to compare?

Finds useful grouping and comparison needs.

5

What feels missing, confusing, or too crowded in this layout?

Invites direct feedback on clarity and visual load.
